# 02: 프로필 및 팔로우 API 구현

이 작업은 Realworld API 명세에 따라 다른 사용자의 프로필을 조회하고, 특정 사용자를 팔로우/언팔로우하는 기능을 구현하는 것을 목표로 합니다.

## 주요 기능

-   **프로필 조회**: 특정 사용자의 프로필(username, bio, image, 팔로우 여부)을 가져옵니다.
-   **사용자 팔로우**: 특정 사용자를 팔로우합니다.
-   **사용자 언팔로우**: 팔로우했던 사용자를 언팔로우합니다.
