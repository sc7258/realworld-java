# 테스트 시나리오: 좋아요(Favorites) API

## 사전 준비
- 사용자 A, 사용자 B가 회원가입 및 로그인되어 있어야 함.
- 사용자 A가 작성한 게시글 P가 있어야 함.

---

### 1. 게시글 '좋아요' 추가 (POST /api/articles/{slug}/favorite)

- **성공 시나리오**
  - **TC1.1**: (인증) 사용자 B가 게시글 P에 '좋아요'를 누른다.
    - **결과**: `200 OK`와 함께 '좋아요' 정보가 갱신된 게시글 객체를 반환한다.
    - **검증**:
      - 반환된 게시글의 `favorited` 필드는 `true`여야 한다.
      - 반환된 게시글의 `favoritesCount`는 1이어야 한다.
  - **TC1.2**: 사용자 B가 이미 '좋아요'를 누른 게시글 P에 다시 '좋아요'를 누른다.
    - **결과**: `200 OK`를 반환하며, `favoritesCount`는 1로 유지된다.

- **실패 시나리오**
  - **TC1.3**: (인증 실패) 인증되지 않은 사용자가 '좋아요'를 시도한다.
    - **결과**: `401 Unauthorized` 오류를 반환한다.
  - **TC1.4**: (존재하지 않는 게시글) 존재하지 않는 `slug`의 게시글에 '좋아요'를 시도한다.
    - **결과**: `404 Not Found` 오류를 반환한다.

---

### 2. 게시글 '좋아요' 취소 (DELETE /api/articles/{slug}/favorite)

- **성공 시나리오**
  - **TC2.1**: (인증) 사용자 B가 '좋아요'를 눌렀던 게시글 P의 '좋아요'를 취소한다.
    - **결과**: `200 OK`와 함께 '좋아요' 정보가 갱신된 게시글 객체를 반환한다.
    - **검증**:
      - 반환된 게시글의 `favorited` 필드는 `false`여야 한다.
      - 반환된 게시글의 `favoritesCount`는 0이어야 한다.
  - **TC2.2**: 사용자 B가 '좋아요'를 누르지 않은 게시글 P의 '좋아요'를 취소하려고 시도한다.
    - **결과**: `200 OK`를 반환하며, `favoritesCount`는 0으로 유지된다.

- **실패 시나리오**
  - **TC2.3**: (인증 실패) 인증되지 않은 사용자가 '좋아요' 취소를 시도한다.
    - **결과**: `401 Unauthorized` 오류를 반환한다.
  - **TC2.4**: (존재하지 않는 게시글) 존재하지 않는 `slug`의 게시글에 '좋아요' 취소를 시도한다.
    - **결과**: `404 Not Found` 오류를 반환한다.

---

### 3. '좋아요' 상태 조회 검증

- **성공 시나리오**
  - **TC3.1**: (게시글 단일 조회) 사용자 B가 게시글 P를 조회했을 때, `favorited` 필드가 `true`이고 `favoritesCount`가 1로 반환되는지 확인한다. (TC1.1 실행 후)
  - **TC3.2**: (게시글 목록 조회) 사용자 B가 게시글 목록을 조회했을 때, 게시글 P 항목의 `favorited` 필드가 `true`이고 `favoritesCount`가 1로 반환되는지 확인한다.
  - **TC3.3**: (다른 사용자 조회) 사용자 A가 게시글 P를 조회했을 때, `favorited` 필드는 `false`이고 `favoritesCount`는 1로 반환되는지 확인한다.
