# 요구사항

1.  **오류 원인 분석**:
    -   `./scripts/run-api-tests.sh` 스크립트를 실행하고, Newman 리포트에서 발생하는 오류 메시지를 정확히 식별합니다.
    -   각 오류가 어떤 API 엔드포인트의 어떤 단언(assertion)에서 발생하는지 파악합니다.

2.  **오류 수정**:
    -   분석된 원인을 바탕으로 Spring Boot 애플리케이션의 관련 코드(컨트롤러, 서비스, 엔티티 등)를 수정합니다.
    -   필요하다면 `openapi.yml` 명세를 수정하고, 관련 API 인터페이스 및 모델을 다시 생성합니다.

3.  **테스트 반복 및 검증**:
    -   코드를 수정한 후, 다시 `./scripts/run-api-tests.sh`를 실행하여 기존 오류가 해결되었는지 확인합니다.
    -   모든 테스트가 통과(0 failures)할 때까지 이 과정을 반복합니다.

4.  **최종 확인**:
    -   스크립트 실행 결과, Newman 리포트에 어떠한 오류도 출력되지 않아야 합니다.
    -   모든 API 테스트 컬렉션이 성공적으로 실행되었음을 확인합니다.
