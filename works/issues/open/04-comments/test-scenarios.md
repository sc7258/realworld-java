# 테스트 시나리오: 댓글(Comments) API

## 사전 준비
- 사용자 A, 사용자 B가 회원가입 및 로그인되어 있어야 함.
- 사용자 A가 작성한 게시글 P가 있어야 함.

---

### 1. 댓글 추가 (POST /api/articles/{slug}/comments)

- **성공 시나리오**
  - **TC1.1**: (인증) 사용자 B가 게시글 P에 성공적으로 댓글을 작성한다.
    - **결과**: `200 OK`와 함께 생성된 댓글 객체(id, body, createdAt, updatedAt, author 프로필 포함)를 반환한다.

- **실패 시나리오**
  - **TC1.2**: (인증 실패) 인증되지 않은 사용자가 댓글 작성을 시도한다.
    - **결과**: `401 Unauthorized` 오류를 반환한다.
  - **TC1.3**: (유효성 검사 실패) 댓글 내용(`body`)이 비어있는 채로 작성을 시도한다.
    - **결과**: `422 Unprocessable Entity` 또는 `400 Bad Request` 오류를 반환한다.
  - **TC1.4**: (존재하지 않는 게시글) 존재하지 않는 `slug`의 게시글에 댓글 작성을 시도한다.
    - **결과**: `404 Not Found` 오류를 반환한다.

---

### 2. 댓글 목록 조회 (GET /api/articles/{slug}/comments)

- **성공 시나리오**
  - **TC2.1**: (비인증) 인증되지 않은 사용자가 게시글 P의 댓글 목록을 조회한다.
    - **결과**: `200 OK`와 함께 해당 게시글의 모든 댓글 목록을 반환한다. (TC1.1에서 작성된 댓글 포함)
  - **TC2.2**: (인증) 인증된 사용자가 게시글 P의 댓글 목록을 조회한다.
    - **결과**: `200 OK`와 함께 모든 댓글 목록을 반환한다. (비인증 조회와 결과 동일)
  - **TC2.3**: 댓글이 없는 게시글의 댓글 목록을 조회한다.
    - **결과**: `200 OK`와 함께 비어있는 댓글 목록(`comments: []`)을 반환한다.

- **실패 시나리오**
  - **TC2.4**: 존재하지 않는 `slug`의 게시글에 대한 댓글 목록 조회를 시도한다.
    - **결과**: `404 Not Found` 오류를 반환한다.

---

### 3. 댓글 삭제 (DELETE /api/articles/{slug}/comments/{id})

- **성공 시나리오**
  - **TC3.1**: (권한 있음) 사용자 B가 자신이 작성한 댓글(TC1.1에서 생성)을 삭제한다.
    - **결과**: `200 OK`를 반환한다.
    - **검증**: 이후 댓글 목록 조회 시 해당 댓글이 없어야 한다.

- **실패 시나리오**
  - **TC3.2**: (인증 실패) 인증되지 않은 사용자가 댓글 삭제를 시도한다.
    - **결과**: `4.1 Unauthorized` 오류를 반환한다.
  - **TC3.3**: (권한 없음) 사용자 A가 사용자 B가 작성한 댓글 삭제를 시도한다.
    - **결과**: `403 Forbidden` 오류를 반환한다.
  - **TC3.4**: (존재하지 않는 댓글) 존재하지 않는 댓글 `id`로 삭제를 시도한다.
    - **결과**: `404 Not Found` 오류를 반환한다.
  - **TC3.5**: (존재하지 않는 게시글) 존재하지 않는 `slug`의 게시글에 포함된 댓글 삭제를 시도한다.
    - **결과**: `404 Not Found` 오류를 반환한다.
