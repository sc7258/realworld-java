# 검증 가이드: API 전체 자동 검증 (Newman)

이 문서는 Realworld 프로젝트에서 공식적으로 제공하는 Postman 컬렉션과 Newman 도구를 사용하여, 우리 백엔드 API 구현 전체가 명세를 준수하는지 자동으로 검증하는 방법을 안내합니다.

이 방법을 사용하면 회원가입, 로그인, 글 작성/수정/삭제, 댓글, 좋아요 등 모든 핵심 API 시나리오를 한 번에 테스트할 수 있습니다.

## 검증 목표

-   우리 애플리케이션이 Realworld API 명세의 모든 요구사항을 충족하는지 확인한다.
-   수동 테스트 없이, 스크립트 실행 한 번으로 모든 API의 동작을 종합적으로 검증한다.

## 전제 조건

-   **Node.js와 npm**이 설치되어 있어야 합니다.
-   **Newman**이 npm을 통해 전역으로 설치되어 있어야 합니다. (최초 1회)
-   검증하려는 **Spring Boot 애플리케이션이 실행 중**이어야 합니다.

## 검증 절차

### 1단계: Newman 설치 (최초 1회)

`newman`은 Postman 컬렉션을 커맨드라인에서 실행해주는 도구입니다. 터미널에서 다음 명령어를 실행하여 시스템에 설치합니다.

```bash
npm install -g newman
```

### 2단계: 검증할 애플리케이션 실행

API 테스트를 수행하기 전에, 검증 대상인 Spring Boot 애플리케이션이 실행되고 있어야 합니다. 예를 들어, `docker` 프로필로 애플리케이션을 실행합니다.

```bash
# 예시: Windows에서 docker 프로필로 실행
.\\gradlew.bat bootRun --args='--spring.profiles.active=docker'
```

### 3단계: API 자동 검증 스크립트 실행

애플리케이션이 실행 중인 상태에서, **새로운 터미널**을 열어 프로젝트 루트 디렉토리의 `scripts` 폴더에 있는 자동 검증 스크립트를 실행합니다.

-   **Windows:**
    ```bash
    scripts\\run-api-tests.bat
    ```

-   **Linux/macOS:**
    ```bash
    # 실행 권한 부여 (최초 1회)
    chmod +x scripts/run-api-tests.sh

    # 테스트 실행
    ./scripts/run-api-tests.sh
    ```

### 4단계: 결과 확인

스크립트가 실행되면, 수십 개의 API 테스트가 순차적으로 진행되며 결과가 터미널에 출력됩니다.

**[예상 결과]**
-   모든 테스트가 끝나면 최종적으로 실행된 테스트 수, 통과(passed), 실패(failed) 횟수를 요약한 표가 나타납니다.
-   모든 기능이 올바르게 구현되었다면, 실패(failed) 횟수가 `0`으로 표시되어야 합니다.
-   만약 실패한 테스트가 있다면, 어떤 API의 어떤 검증 항목에서 문제가 발생했는지 상세한 오류 내용이 함께 출력됩니다.

---

이 자동 검증은 새로운 기능을 추가하거나 기존 코드를 수정한 후, 변경 사항이 다른 API에 영향을 주지 않았는지(회귀 테스트) 확인하는 데 매우 유용합니다.
